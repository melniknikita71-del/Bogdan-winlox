# BogdanLocker Demo

Безопасная Android Studio демонстрация хоррор-экрана.

## Запуск
1. Распакуйте архив.
2. Откройте папку `BogdanLockerDemo` в Android Studio.
3. Дождитесь Gradle Sync.
4. Выберите телефон/эмулятор и нажмите Run.
5. Для демонстрационного завершения введите `7777`.

## Ограничения безопасности
- Это обычное приложение, не настоящий блокировщик.
- Не запрашивает разрешение «поверх других окон».
- Не запускается скрытно и не блокирует системные жесты, уведомления, настройки или перезагрузку.
- Кнопка «ВЫЙТИ ИЗ ДЕМО» доступна на каждом экране.
- Таймер декоративный; по его завершении ничего не происходит.
